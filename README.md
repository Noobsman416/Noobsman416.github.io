# Noobsman416.github.io
ナイトレインTRPGにローグライク要素として、原作にもあった遺物システムを追加します。難易度が低下、バランスが壊れる可能性もあるので、適宜調整や敵の強さを上げたりしてみてください。

〇概要
マッチ終了後のローグライク要素を追加します。
添付ファイルはマッチ終了後に得られる遺物を自動的に出すものとなっております。

遺物は大・中・小があり、プレイヤーは遺物を3つ、深き夜では6つ付けてマッチに出撃することが出来ます。
小：効果が1つ付く
中：効果が2つ付く
大：効果が3つ付く

重複不可とは、その遺物効果の重複不可のことであり、同じ効果が別々に遺物で揃っていても問題はない。(ただし効果は一つしか発動しない)
